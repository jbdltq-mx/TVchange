# My Fire TV Stick (older, Android-based Fire OS 6/7/8; exact model to be read with tools/tv.py --probe).
# Based on examples/amazon-fire-tv-stick-4k-2018 (tested on Fire OS 6.7.1.1), with the Fire OS 7 names from the
# Toshiba and Insignia lists added so it also fits a newer stick. A package your stick doesn't have, or that Fire OS
# protects, just prints an error and is skipped; everything else still applies.
#
# Apply:   TV_HOST=<stick ip> tools/disable.sh my-fire-tv/debloat.txt
# Undo:    TV_HOST=<stick ip> tools/restore.sh my-fire-tv/debloat.txt com.amazon.tv.launcher
# Everything is DISABLED for user 0, never uninstalled. Comment out any line you want to keep.
#
# FIRE OS: DEBLOAT ONLY. Amazon's home screen is protected, so launcher/ does not apply and the "Sponsored" banner
# stays (see README.md in this folder for the optional ad-blocking DNS that empties it).
#
# Kept on purpose (not listed): Netflix, Prime Video, Disney+, YouTube, Max; Alexa voice search on the remote mic
# (com.amazon.vizzini, com.amazon.aria, com.amazon.cardinal); firmware updates (OTA); Appstore; settings; keyboard;
# remote and Bluetooth; the Fire TV phone-remote link (whisperlink / whisperplay); screensaver; profiles.
# Switched off by choice: screen mirroring and casting from phone apps, Alexa extras, unused streaming apps.
